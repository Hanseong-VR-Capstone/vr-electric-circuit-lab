문서명: Week5_OhmsLawCalculation_v1

목적
rail 기반 회로에서 옴의 법칙을 이용한 기본 계산을 수행한다.

--------------------------------

1. 계산 대상

- 전체 저항
- 전체 전류
- 부하별 전압

--------------------------------

2. 전원 기준

- rail 기반 전원 사용
- GetRailSupplyVoltage()

--------------------------------

3. 직렬 회로

- R_total = R1 + R2 + ...
- I = V / R_total
- V_i = I * R_i

--------------------------------

4. 병렬 회로

- 1 / R_total = Σ(1 / R_i)
- V_i = V
- I_i = V / R_i

--------------------------------

5. 출력

CircuitCalculationResult 사용
