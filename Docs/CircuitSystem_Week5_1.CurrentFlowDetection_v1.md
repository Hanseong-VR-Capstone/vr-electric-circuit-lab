문서명: Week5_CurrentFlowDetection_v1

목적
회로 내에서 전류가 흐르는 wire를 판정하는 구조를 설계한다.

--------------------------------

1. 현재 상태

- 회로는 그래프 기반으로 구성됨
- plus rail → minus rail 경로 존재 여부는 이미 판정 가능

--------------------------------

2. 전류 흐름 정의

전류 흐름이란:
- plus rail에서 minus rail로 이어지는 경로에 포함된 edge

--------------------------------

3. 목표

- 현재 회로에서 전류가 흐르는 wire 목록 반환
- 이후 이펙트 시스템에 전달

--------------------------------

4. 출력 구조

- isFlowing
- activeWireIds

--------------------------------

5. 설계 원칙

- Evaluate 수정하지 않음
- 별도 helper로 분리
- 그래프 재사용

--------------------------------

6. 핵심 한 줄

"plus → minus 경로에 포함된 wire를 active로 판단"
