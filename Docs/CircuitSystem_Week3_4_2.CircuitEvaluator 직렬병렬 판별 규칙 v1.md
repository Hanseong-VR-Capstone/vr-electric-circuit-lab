문서명: CircuitEvaluator 직렬/병렬 판별 규칙 v1

목적
현재 그래프 기반 회로 엔진 위에서
교육용 직렬 / 병렬 회로 판별 규칙을 정의한다.

이 문서는:
- 회로 구조 판별 기준을 고정하고
- 이후 전압 분배 및 상태 확장 기반을 제공한다

--------------------------------
[1] 전제 조건

현재 시스템은 다음 구조를 따른다:

- Node = socket.nodeId
- Pin -> Socket -> NodeId
- Edge = wire / switch(isOn)

LED는 일반 edge가 아니라
극성 판정용 특수 부품으로 유지한다.

--------------------------------
[2] 그래프 정의

회로는 다음 그래프로 해석된다:

- Node = nodeId
- Edge = wire 또는 활성화된 switch

즉 CircuitEvaluator는
node graph 기반으로 동작한다.

--------------------------------
[3] 직렬 회로 정의 (교육용 단순화)

직렬 회로는 다음 조건을 만족한다:

1. battery+ → battery- 경로가 존재한다
2. 그래프에 분기점이 없다

분기점 정의:
- 하나의 node가 3개 이상의 neighbor를 가짐

즉:
- degree(node) < 3 for all nodes

결론:
- 경로가 하나뿐인 단순 구조 → 직렬

--------------------------------
[4] 병렬 회로 정의 (교육용 단순화)

병렬 회로는 다음 조건 중 하나라도 만족하면 된다:

1. battery+ → battery- 경로가 2개 이상 존재
2. 그래프에 분기점 존재

즉:
- HasBranching == true
또는
- Path count >= 2

--------------------------------
[5] 경로 수 정의

경로 수는 다음 방식으로 계산한다:

- DFS 기반 탐색
- 같은 node 재방문 금지
- target 도달 시 카운트 증가
- 일정 개수 이상이면 탐색 중단

최대 탐색 개수:
- 2개 이상이면 병렬 판정 충분

--------------------------------
[6] 구현 함수 정의

CircuitEvaluator에 다음 함수 추가

1. HasBranching(graph)

- 역할:
  node 중 neighbor 수 >= 3 인지 검사

2. CountPaths(start, end, graph, maxSearch)

- 역할:
  start → end 경로 개수 계산
- DFS 기반
- maxSearch 도달 시 종료

3. IsSeriesCircuit(...)

조건:
- HasPath == true
- HasBranching == false

4. IsParallelCircuit(...)

조건:
- HasPath == true
- (HasBranching == true OR CountPaths >= 2)

--------------------------------
[7] 현재 단계 제한

이번 단계에서는 다음을 하지 않는다:

- 전압 계산
- 저항 계산
- 실제 전류 계산
- 복잡한 회로 해석

이 단계는 “구조 판별”만 수행한다.

--------------------------------
[8] Evaluate()와의 관계

현재 Evaluate()는 유지한다.

- Open
- LedOn
- Short

직렬/병렬 판별은
Evaluate 내부에 직접 넣지 않는다.

이유:
- 책임 분리 유지
- 이후 상태 확장 대비

--------------------------------
[9] 설계 의도

이 규칙은 다음을 목표로 한다:

- 교육용 단순 회로 이해
- 복잡한 물리 계산 제거
- 그래프 기반 직관적 판정

--------------------------------
[10] 핵심 요약

직렬:
- 경로 1개
- 분기 없음

병렬:
- 경로 2개 이상
- 또는 분기 존재
