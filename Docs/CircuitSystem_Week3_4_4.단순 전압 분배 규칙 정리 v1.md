문서명: 단순 전압 분배 규칙 정리 v1

목적
현재 그래프 기반 회로 엔진 위에서
교육용 단순 전압 분배 규칙을 정의한다.

이 문서는:
- 직렬 / 병렬 구조 판별 결과를 전압 해석과 연결하고
- 이후 설명용 UI 및 튜토리얼 문구의 기준을 제공하며
- 복잡한 물리 계산 없이 교육용 단순화 규칙을 고정한다

--------------------------------
[1] 현재 전제

현재 CircuitEvaluator는 다음 기반을 이미 가진다.

- BuildNodeGraph()
- HasPath()
- IsValidLedPath()
- IsSeriesCircuit()
- IsParallelCircuit()

즉 현재 시스템은
회로가 연결되었는지
LED 극성이 맞는지
구조가 직렬인지 병렬인지
판별할 준비가 되어 있다.

:contentReference[oaicite:1]{index=1}

--------------------------------
[2] 이번 단계 목표

이번 단계는 “정밀 전기 시뮬레이터”가 아니다.

이번 단계의 목표는
교육용 단순 규칙으로 전압 분배를 설명 가능한 형태로 만드는 것이다.

즉:
- 실제 전류 계산 없음
- 실제 저항값 기반 정밀 계산 없음
- 키르히호프 법칙 전체 구현 없음

대신 아래 규칙만 사용한다.

--------------------------------
[3] 배터리 전압 기준

배터리 하나를 기준으로 해석한다.

- CircuitBattery.voltage 값을 전체 공급 전압으로 사용
- 현재 1차 기준은 primary battery 하나만 사용
- Evaluate와 동일하게 Batteries[0]을 기준 배터리로 본다

:contentReference[oaicite:3]{index=3}

--------------------------------
[4] 직렬 회로 전압 규칙

직렬 회로의 교육용 단순 규칙

1. 전체 전압은 직렬로 연결된 부하들에 나뉜다
2. 현재 단계에서는 각 부하의 저항값이 없으므로
   “동일 분배” 규칙을 사용한다
3. 즉 직렬 부하가 N개면
   각 부하 전압 = batteryVoltage / N

예
- battery = 3.0V
- 직렬 부하 3개
- 각 부하 전압 = 1.0V

주의
- 이건 교육용 단순화 규칙이다
- 실제 회로에서는 저항값에 따라 다를 수 있다

--------------------------------
[5] 병렬 회로 전압 규칙

병렬 회로의 교육용 단순 규칙

1. 각 병렬 branch는 동일한 공급 전압을 가진다
2. 즉 각 병렬 branch 전압 = batteryVoltage

예
- battery = 3.0V
- 병렬 branch 2개
- 각 branch 전압 = 3.0V

주의
- 이 단계에서는 전류 분배는 다루지 않는다
- 전압만 동일하다고 본다

--------------------------------
[6] 이번 단계의 부하 해석 단위

현재 단계에서는 “부하(load)”를 단순하게 본다.

교육용 1차 기준:
- LED 1개 = 부하 1개
- 이후 필요하면 저항, 모터 등도 부하로 확장 가능

즉 현재 직렬 전압 분배 계산의 기본 대상은
“회로에 포함된 LED 개수” 또는
“판정 대상 부품 개수”
정도로 단순화한다.

--------------------------------
[7] 구현 함수 방향

이번 단계에서 CircuitEvaluator 또는 관련 helper에
다음 성격의 보조 함수를 추가한다.

1. float GetPrimaryBatteryVoltage()
역할
- primary battery 전압 반환
- 없으면 0

2. int CountActiveLoads()
역할
- 현재 회로에서 전압 분배 대상으로 볼 부하 개수 반환
- 1차 기준으로는 연결된 LED 수 또는 유효 LED 수 기반 단순화 가능

3. float CalculateSeriesVoltagePerLoad(...)
역할
- 직렬 구조일 때 부하당 전압 계산
- batteryVoltage / loadCount

4. float CalculateParallelBranchVoltage(...)
역할
- 병렬 구조일 때 branch 전압 계산
- batteryVoltage 그대로 반환

--------------------------------
[8] 현재 단계에서의 사용 원칙

이번 단계에서 전압 계산 결과는
최종 CircuitState를 바꾸기 위한 용도가 아니다.

즉:
- Open / LedOn / Short 판정은 그대로 유지
- 전압 계산은 보조 정보다
- 이후 설명 UI, 디버그 출력, 튜토리얼 문구 등에 활용 가능

--------------------------------
[9] 이번 단계에서 하지 않을 것

- 저항값 기반 전압 분배
- 전류 계산
- 전력 계산
- 다중 배터리 합성
- 복잡한 branch별 정밀 계산

--------------------------------
[10] 핵심 요약

직렬:
- 전체 전압을 부하 수로 균등 분배

병렬:
- 각 branch가 전체 전압을 그대로 가짐

이 규칙은 교육용 단순화 규칙이다.
